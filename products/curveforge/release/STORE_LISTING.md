## Full description

CurveForge turns an ordered set of control points into a reusable building path in Roblox Studio.

Create overhead utility cables, industrial pipes and hoses, or distribute your own fence posts, decorations and other models along a curve. Review the result before changing your place.

- Use 2-8 existing control parts or create editable markers with New Path.
- Choose cable thickness, segment length, color, material, anchoring, collision and shadows.
- Repeat a Part or Model by spacing or count, include/exclude endpoints and control tangent orientation and local rotation offset.
- Reopen a generated model, move its original control points, preview and explicitly regenerate.
- Undo or redo a build/regeneration as one Studio operation.

Original objects remain intact. Preview uses the plugin panel and does not insert anything into your project. Generated output is ordinary Roblox instances with transparent metadata.

## Limitations

Open paths only; up to 8 control points, 512 cable segments, 500 copies and 5000 repeated instances. Cables use cylinders and rounded interior joints, not hollow pipe meshes. Sources must be Archivable, without scripts or external object/joint references. Preserve source/control objects for later edits. New Path markers are visible until hidden in Properties. Spacing is approximate arc-length spacing; including endpoints can make the final interval shorter. Uniform Catmull-Rom curves can overshoot or self-intersect on tight/uneven controls. No physics rope simulation, roads, terrain or runtime spline API. Eight built-in materials.

Privacy: No HTTP, analytics, telemetry, AI, backend or external runtime dependencies. Metadata stays in your place. No data is sent by the plugin.
