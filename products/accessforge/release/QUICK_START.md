# Quick Start

1. Open AccessForge from Studio's Plugins toolbar, outside Play mode.
2. Choose **Straight**, **Switchback** or **Catwalk**, then **New markers**. Move Start and End in Studio. Alternatively select one BasePart and assign it with Start/End.
3. Adjust Layout, Rails and Finish. Preview checks dimensions and shows the calculated structure and part count without building in Workspace.
4. Click **Build**, review the count, then **Confirm Build**. Studio Undo/Redo applies to the whole build.
5. Later, select the generated assembly Model and click **Edit Existing**. Change settings or move the original markers; Preview, then Regenerate and confirm.

Straight: Start is lower; End is the last tread's top elevation. A top landing extends beyond End. Catwalk: both markers must have the same height. Switchback: Start and End are the adjacent lower/upper entrances, not the far landing; place them at least Width + 0.5 studs apart. Left/Right flips the direction the flights extend.

Keep control markers and `AccessForgeData`. Put custom additions beside generated Parts, not inside them. Widen the panel or use its scrollbars if Studio docks it tightly.
