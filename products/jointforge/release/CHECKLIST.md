# Release gate

- Rebuild and run `tools/verify_release.py`; confirm the binary and six script sources match.
- Run the 14 edit-mode Studio test groups. Check `tests/RESULTS.md` for actual execution evidence.
- Complete the novice one-minute trial and the manual comparison in `tests/STUDIO_CHECKLIST.md` before claiming commercial usability or time savings.
- Review the three real Studio screenshots and the store limitations. Set the final price yourself.
- Upload only `dist/JointForge-v1.0.0.rbxm` as a plugin. No upload/account/payment action is automated by this repository.
