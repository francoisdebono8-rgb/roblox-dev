# SchemaForge 1.0.0

Title: SchemaForge - Tagged Object Configuration Audit

Suggested price: USD 4.99. Price hypothesis, not validated demand.

## Creator Store description

Catch misconfigured tagged objects before playtesting.

SchemaForge saves explicit configuration rules in your project: required attributes, number ranges, integer values, allowed strings, designer notes and required child paths with expected classes.

Capture a reference, refine the rules, then audit selected roots and descendants or the Workspace. Select affected objects directly from the findings.

Preview optional repairs before applying them. Only missing required attributes with enabled defaults are added. Existing values, wrong types and children are never overwritten. Native Studio Undo/Redo supports repairs and schema storage changes.

V1 supports number, string and boolean attributes. Edit mode only; no runtime enforcement or automatic hierarchy repair. No HTTP, analytics or external services. Best for teams reusing configured gameplay objects.

## Privacy

Entirely local Studio processing. Project schemas are readable JSON StringValues under ServerStorage/_SchemaForgeSchemas. No network requests, analytics, telemetry, account data or runtime scripts.
