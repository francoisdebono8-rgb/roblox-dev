# SchemaForge 1.1.0

Title: SchemaForge - Tagged Object Configuration Audit

Suggested price: USD 4.99. Price hypothesis, not validated demand.

## Creator Store description

Catch misconfigured tagged objects before playtesting. Save explicit project contracts for attributes, numeric ranges, string choices, designer notes and required child paths/classes.

Capture a reference or load a saved contract. Audit selected roots and descendants or Workspace. Read Expected, Actual and notes in each finding; filter by reason or field and select an affected subset.

Preview conservative repairs with an exact count. Only missing required attributes with enabled defaults are added. Existing values, wrong types, tags and children stay untouched. Stale previews block Apply. Repairs and schema saves use native Studio Undo/Redo.

Compact Rules, Audit and Repairs views follow Studio's theme. Number, string and boolean attributes only. Edit mode; no runtime enforcement, inferred correctness or automatic hierarchy repair. No HTTP, analytics or external services.

## Privacy

Entirely local Studio processing. Project schemas are readable JSON StringValues under ServerStorage/_SchemaForgeSchemas. No network requests, analytics, telemetry, account data or runtime scripts.
