# Quick start

1. Open SchemaForge from Studio's Plugins menu in edit mode.
2. Select one correctly configured, tagged object and click **Capture reference**.
3. Name the schema. Set the exact tag, expected class, attribute rules and required child paths. Save it in this project.
4. Open **Audit**. Choose selected roots (including descendants) or Workspace; click **Audit tagged objects**.
5. Select findings to inspect them. **Preview missing defaults** lists only absent required attributes whose default you explicitly enabled. Apply when appropriate; Studio Undo reverses the change.

Reload or edit saved rules from **Project schemas**. Save the place to persist them.
