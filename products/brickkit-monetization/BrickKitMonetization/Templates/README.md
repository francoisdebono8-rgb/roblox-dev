# Templates

`MonetizationClient` is a deliberately minimal LocalScript placeholder for the future client/UI issue.

The future package must add a `ScreenGui` named `BrickKitShop` here with `ResetOnSpawn = false`. `MonetizationServer` already clones these two templates once into `PlayerScripts` and `PlayerGui` without overwriting existing objects. No visual design is included in M2.1.
