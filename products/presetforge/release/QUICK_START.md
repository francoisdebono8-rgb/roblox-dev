# Quick start

1. Open PresetForge from Studio's **Plugins** toolbar.
2. In **Library**, select one configured object and click **Save Recipe**.
3. Check only the fields PresetForge may change; choose **Local** or **Project**.
4. Select target objects, or containers for **Descendants** mode.
5. Add class, name, or tag filters when using descendants.
6. Click **Preview**. Review changed objects first; **Select affected** or **Frame affected** locates them.
7. Click **Apply**. One Studio Undo restores the complete operation.

Preview is read-only. Saving a recipe does not change source objects; Project recipes are stored under ServerStorage. Unchecked fields and unrelated tags or attributes are preserved.

Search names in Library. Use Duplicate in Recipe, give the copy a new name, then Edit it from a compatible source. The original stays unchanged.
