# FOUNDATION 01 — carte de recherche et décisions A–K

Audit externe effectué le **10 octobre 2026**, pas une liste de liens suggérés. GitHub : API metadata/arbre/commit, licences textuelles et fichiers ciblés lus. Roblox : documentation, annonces et posts publics ; les pages DevForum refusant le lecteur web ont été lues via leur endpoint JSON public. YouTube : pages publiques, métadonnées/descriptions/chapitres et code associé quand accessible ; **pas de prétention à avoir visionné intégralement les vidéos**, pas de timestamps inventés. Les .rbxm d'animation ont été téléchargés en espace temporaire et désérialisés comme données ; aucun script tiers n'a été exécuté.

IMPORT/ADAPT expriment un choix **pour une future implémentation approuvée**, jamais un import fait par cette mission. « Vérifié » = code/données réellement présents, pas preuve de maturité en production ou de qualité de jeu. Les inconnues natives restent dans le plan. Aucune solution payante retenue.

Lecture des tables : le code MIT vérifié exige maintien des notices ; une licence de code ne garantit pas les droits des animations/sons référencés. Roblox-native signifie usage de la plateforme selon ses conditions, pas module sous MIT ; [creator-docs](https://github.com/Roblox/creator-docs/blob/main/LICENSE) est CC-BY-4.0 pour la documentation. Licence absente = REFERENCE ONLY, même quand l'auteur propose une vidéo ou un modèle gratuit.
