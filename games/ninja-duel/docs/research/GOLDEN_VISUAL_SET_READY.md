# Immediate comparison sheet Claude must use

Before adding new moves, put Ninja Duel next to the references above and grade 0–2:

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Run/sprint body intent | slides / generic | readable but weak | obvious support/cadence/acceleration |
| Direction change | root snap | body partially follows | feet/hips/torso explain change |
| Jump/traversal | Roblox hop | usable | anticipation + horizontal intent + clean landing |
| Wall transition | snap/stick | functional | momentum + target awareness preserved |
| Jab/punch | arm-only/dance | contact readable | support→hip→torso→shoulder→fist→recovery |
| Kick | decorative spin | readable attack | support/pivot/impact/retraction all clear |
| Ground combo | pose chain | coherent | controllable exchange with purposeful conversions |
| Air combo | float/string | usable | launch/pursuit/contact/exit all intentional |
| Defense | button state | readable | body reaction + timing + counter opportunity |
| Kunai/shuriken | cooldown projectile | integrated | movement/angle/state decision created |
| Weapon | mesh swap | route variant | geometry/body/range/recovery genuinely change |
| Camera | fights the action | acceptable | speed + contact + feet/opponent readable |

**Stop condition:** if a category scores 0, do not mask it with FX. Fix/rebuild body, transition or camera first.
