# Combo Building Blocks

This file is a reusable catalogue for Claude. These are optional building blocks, not mandated current moves.

## Grounded branches

- Neutral string: reliable pressure, moderate pushback.
- Up branch: launcher or rising strike.
- Down branch: sweep, body drop or ground bounce.
- Side branch: angle change, side switch, chop, hook, palm redirect or throw entry.
- Hold attack: delayed heavy / guard pressure / launcher variant.
- Movement attack: running strike, sliding entry, shoulder, flying kick or teleport entry depending on character.

## Projection families

### Basic hip/shoulder throw
Best for balanced taijutsu users.
Result: side knockdown, wall setup if near edge.

### Leg reap / sweep throw
Best for Neji, Kakashi, grounded technical fighters.
Result: low knockdown, fast reset.

### Momentum throw
Use opponent's forward movement against them.
Best for counter specialists.

### Aerial throw
Catch airborne opponent and redirect toward ground or wall.
Best for Lee, Sasuke, Minato.

### Wall projection
Grab or strike sequence that turns wall proximity into a new route.

### Character power projection
Sand drag, snake bind, clone-assisted throw, chakra palm displacement, teleport inversion.

## Launcher families

- Uppercut/rising palm.
- Rising kick.
- Sweep-to-pop-up.
- Chakra burst under target.
- Projectile lift/setup.
- Teleport below target.
- Clone-assisted launch.

Launchers should differ in height, horizontal travel, recovery and follow-up freedom.

## Aerial route families

- Fast chase string: low commitment, quick return to ground.
- Carry route: moves target horizontally toward wall.
- Vertical route: gains height for air-to-ground finisher.
- Cross-under route: attacker passes target and changes side.
- Projectile route: tools keep target suspended or force trajectory.
- Teleport route: attacker repositions between hits.
- Grapple route: air catch -> directional throw.

## Air-to-ground finishers

- Heel drop.
- Downward palm.
- Rasengan plunge.
- Sand slam.
- Clone pile-driver style assist.
- Snake drag.
- Chidori dive prototype.

## Wall route families

- Wall splat -> direct follow-up.
- Wall bounce -> pursuit.
- Attacker wall-run -> dive attack.
- Defender wall-tech -> neutral reset.
- Side wall carry -> projection.
- Projectile pin -> approach.
- Marked surface -> teleport route.

## Counter routes

- Perfect guard -> guaranteed light punish.
- Dodge -> side/rear punish.
- Projectile deflect -> return pressure.
- Genjutsu bait -> counter window.
- Rotation/parry -> palm follow-up.
- Clone substitution -> flank.
- Movement read -> intercept.

## Tool integration

Standard ninja tools should be usable by many fighters. Mastery changes what they can do with them.

Generic uses:
- neutral poke,
- interrupt approach,
- force dodge,
- aerial throw,
- cancel recovery,
- pin to surface,
- start pursuit.

Advanced mastery:
- ricochet,
- projectile-on-projectile redirection,
- delayed second throw,
- wire control,
- marked kunai,
- clone-assisted angle,
- fire-enhanced projectile,
- trap trigger.

## Character examples

### Minato
Neutral string -> side branch -> marked kunai -> pursuit option.
Launcher -> FTG chase -> aerial kick -> Rasengan plunge.
Projection -> throw target toward planted seal -> teleport punish.

### Itachi
Light string -> deliberate gap -> shuriken forcing dodge -> counter route.
Launcher -> delayed shuriken intersects descent -> fire follow-up.
Side branch -> feint/afterimage -> rear strike.

### Neji
Palm string -> side circle -> tenketsu hit -> chakra restriction.
Low sweep -> standing palm reset.
Counter -> Rotation -> thrust.

### Sasuke
Aggressive string -> launcher -> aerial kicks -> down-smash.
Shuriken + wire -> forced movement -> Fireball lane control.
Side branch -> Lion Combo style continuation.

### Naruto
Clone feint -> opposite-side strike.
Launcher -> clone chase -> aerial swarm -> slam.
Projection -> clone catches recovery.

### Gaara
Approach denial -> sand pop-up -> ranged continuation.
Wall splat -> sand bind -> displacement.
Projection equivalent -> sand hand throws target.

### Kakashi
Read repeated attack -> dodge-counter -> lightning-enhanced finisher.
Tool cancel -> element switch -> reposition.

### Orochimaru
Extended limb strike -> bind -> side-switch.
Underground shift -> rear launcher.
Snake grab -> wall throw.

### Shisui
Burst entry -> afterimage side branch -> cross-up.
Launcher -> body-flicker air chase -> reappear behind target.

### Lee
Pressure string -> rising kick -> physical chase -> spinning air kick -> ground finish.
Side branch -> 360 kick.
Projection -> immediate pursuit.

## Quality rules

- A route must be visually readable.
- Different branches need different silhouettes, not only different hit properties.
- Keep player agency: avoid long automatic cinematics.
- Every major route should have at least one defensive answer.
- Avoid one universally optimal combo.
- Route value should vary with space, wall proximity, chakra, opponent state and character identity.
