# Rendus 3D des offres (ANIMATEUR, étape 5)

Un PNG 512 × 512 à fond transparent par look vendu ou donné (le nom du fichier est l'`id` du Catalog), sur l'avatar de départ (tunique noire, pantalon sombre) quand le look n'est qu'une pièce. Les capes et les pièces de dos sont vues de dos ; les coiffures, bandeaux et masques en buste ; les armes seules. Les auras sont des formes fixes qui évoquent les particules du jeu.

`SetBundle8.png` : les 8 tenues des prodiges ensemble, pour le lot.

Pour la DESIGN : à poser sur le papier et l'encre de la DA v3 (`assets/offers/generate_offers.py`). Refaire : `tools/blender/offer_renders.py offers DST` dans Blender, puis `python3 tools/blender/offer_bundle.py DST` ; les PNG sont réduits à 256 couleurs.
