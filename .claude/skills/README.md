# Skills de projet (Claude Code)

Chargées automatiquement par Claude Code quand on travaille dans ce dépôt.

| Skill | Origine | Pourquoi pour Ninja Duel |
|---|---|---|
| `graphify` | [graphify](https://github.com/safishamsi/graphify) (Apache-2.0), paquet PyPI `graphifyy` | Graphe de connaissances du code. Celui de `games/ninja-duel/` est dans `games/ninja-duel/graphify-out/` (`graphify query "…"`, `graphify update .` après des changements, sans coût d'API). |
| `game-feel` | [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) (Apache-2.0) | Impact des coups : hit-stop, secousses, knockback, retours audio-visuels. |
| `camera-systems` | idem | Caméra de combat : cadrage de plusieurs cibles, lissage, collisions. |
| `audio-design` | idem | Bruitages en couches, ducking, musique adaptative. |
| `game-ai` | idem | Comportement du bot (FSM, arbres de comportement, steering). |
| `roblox-characters` | idem | Rigs R15, Animator, marqueurs d'animation, cycle de vie des persos. |
| `roblox-networking` | idem | Remotes, autorité serveur, prédiction et propriété réseau (le joueur pilote son corps). |
| `roblox-physics` | idem | Assemblies, collisions, impulsions, propriété réseau. |
| `roblox-studio-workflow` | idem | Modifier une place Studio vivante sans casser l'existant. |

Les skills du plugin `roblox-dev` (architecture, sécurité, performance, UI, tests, DataStores, typage strict) restent la référence sur ces sujets ; celles-ci les complètent.
