# SchemaForge — canonical product identity

Source family: approved SchemaForge cover.
Shared mark: `../assets/forge-f.svg`.
Canonical accent: **#63D6AE** premium mint.

## Cover meaning
The cover communicates:
tagged/project objects -> explicit contract -> audit results -> missing-only repair.

The green/mint belongs to the product identity.
The red/orange finding colors remain semantic diagnostics.

## In-product signature
SchemaForge should be recognizable through:
- contract context;
- rules/findings marker language;
- Expected / Actual comparison;
- safe repair surface;
- analytical mint accent.

Best places for mint:
- active rule/finding;
- focus;
- repairable indicator;
- safe repair;
- primary action.

Avoid:
- green screen wash;
- treating all valid/success states as brand mint;
- generic checkmark branding everywhere.

## Brand hierarchy
Product first: SchemaForge.
Maker second: Forge Studio + canonical F.
Document third: active contract.

The F geometry is fixed; never retrace from the raster cover.
