# CurveForge — canonical product identity

Source family: approved CurveForge cover.
Shared mark: `../assets/forge-f.svg`.
Canonical accent: **#4D7DD2** steel/electric blue.

## Cover meaning
The cover communicates:
ordered control points -> custom path -> cable/pipe/repeated model output.

## In-product signature
CurveForge should be recognizable through:
- ordered control points;
- path geometry;
- Cable / Repeat mode;
- large contextual preview;
- blue proposed output.

Best places for blue:
- selected control point;
- active path;
- preview curve;
- output-mode selection;
- primary build/regenerate action.

Avoid:
- using blue as generic UI chrome everywhere;
- burying the path preview under settings;
- generic stacked point rows with text Up/Down/Remove.

## Brand hierarchy
Product first: CurveForge.
Maker second: Forge Studio + canonical F.
Current path/model is the work identity.

The F geometry is fixed; never retrace from the raster cover.
