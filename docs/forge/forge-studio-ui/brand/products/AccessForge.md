# AccessForge — canonical product identity

Source family: approved AccessForge cover.
Shared mark: `../assets/forge-f.svg`.
Canonical accent: **#A34BC5** refined violet / magenta-violet.

## Cover meaning
The cover communicates:
industrial stairs / switchbacks / landings / catwalks / rails as one editable assembly.

The bright yellow rails in the cover are a **material/safety cue**, not the brand accent.

## In-product signature
AccessForge should be recognizable through:
- Start / End relationship;
- industrial assembly mode;
- structure dimensions;
- assembly preview;
- refined violet selection language.

Best places for violet:
- active structure mode;
- selected endpoint;
- selected assembly;
- preview emphasis;
- primary build/regenerate state.

Avoid:
- replacing violet with safety yellow as the product brand;
- treating the plugin like a generic CAD form;
- horizontal-scroll layouts.

## Brand hierarchy
Product first: AccessForge.
Maker second: Forge Studio + canonical F.
Current assembly is the work identity.

The F geometry is fixed; never retrace from the raster cover.
