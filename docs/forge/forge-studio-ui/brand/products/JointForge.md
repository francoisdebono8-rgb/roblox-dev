# JointForge — canonical product identity

Source family: approved JointForge cover.
Shared mark: `../assets/forge-f.svg`.
Canonical accent: **#D77A3E** copper / warm orange-metal.

## Cover meaning
The cover communicates:
Part0 + Part1 -> explicit mechanical connection -> joint/constraint.

## In-product signature
JointForge should be recognizable through:
- Part0 / Part1 endpoint relationship;
- visible joint type;
- Create / Batch / Inspect distinctions;
- exact planned operation;
- copper connection emphasis.

Best places for copper:
- endpoint pairing;
- active joint/connection;
- selected joint;
- preview operation;
- primary create/apply action.

Avoid:
- orange warning semantics being indistinguishable from brand copper;
- raw technical paths as primary identity;
- generic stacked forms for Create/Batch/Inspect.

## Brand hierarchy
Product first: JointForge.
Maker second: Forge Studio + canonical F.
Current connection/joint is the work identity.

The F geometry is fixed; never retrace from the raster cover.
