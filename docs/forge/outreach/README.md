# Forge Outreach Library

Purpose: keep a reusable list of places where each Forge plugin genuinely solves a problem already discussed by Roblox developers, plus launch copy ready for Community Resources.

## Rules

- Research current Roblox Developer Forum discussions for every new Forge product before or immediately after publication.
- Mine **Studio Features**, **Building Support**, **Community Resources**, and the **plugins tag** systematically.
- Add only discussions where the product directly addresses the stated problem.
- Prefer recent, still-open support or feature-request threads over old threads.
- Re-check that the topic is still open before posting.
- Never advertise inside a direct competitor's own showcase/support thread.
- Never pretend to be an unaffiliated user. Disclose that the plugin is ours and paid when applicable.
- Lead with the solution/use case, not a sales pitch.
- Do not mass-post the same copy. Adapt each reply to the exact thread.
- If replying would mainly revive an old solved thread without adding useful information, skip it.
- After a plugin is published, replace any `[CREATOR_STORE_LINK]` placeholder with its real public link.

## Posting authority

- Codex may prepare launch/reply copy by default.
- When the user explicitly asks for end-to-end promotion/announcement, Codex should also post through the authenticated DevForum session **if posting permissions are available**.
- If DevForum posting permission is unavailable, do not claim the post succeeded. Store the final copy and record the blocker.
- Do not bypass forum permissions, anti-spam controls, account restrictions or closed topics.

## Required step for every future Forge product

Before marking the release pipeline complete, add at least:
1. 3-5 targeted DevForum search queries used;
2. all high-confidence relevant threads found;
3. thread URL, date/category, fit rationale and current open/closed check;
4. one short tailored reply draft per high-confidence thread;
5. a USE / SKIP decision;
6. one Community Resources launch-post draft;
7. actual post URLs when posting was explicitly requested and permissions allowed.

Primary file: `docs/forge/outreach/devforum-opportunities.md`.

See also: `docs/forge/forge-product-factory.md`.
