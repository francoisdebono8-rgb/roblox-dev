# PresetForge — canonical product identity

Source family: approved PresetForge cover.
Shared mark: `../assets/forge-f.svg`.
Canonical accent: **#D1A348** warm amber / yellow-orange.

## Cover meaning
The cover communicates:
one source -> reusable recipe -> selected properties/tags/attributes -> many targets.

## In-product signature
PresetForge should be recognizable through:
- recipe library;
- source/recipe lineage;
- captured-field summaries;
- targets;
- before/after changes.

Best places for amber:
- selected recipe;
- captured-field markers;
- source/recipe relationship;
- Preview/Apply-ready state.

Avoid:
- orange warning semantics using the exact brand treatment;
- five orange cards;
- turning Recipe into a generic settings form.

## Brand hierarchy
Product first: PresetForge.
Maker second: Forge Studio + canonical F.
Current recipe is the active work identity.

The F geometry is fixed; never retrace from the raster cover.
