## Exact Creator Store Description

Build editable industrial stairs, landings and catwalks directly in Roblox Studio. Choose your start and end elevations, preview the calculated structure, then generate clean Roblox-native geometry without manually duplicating and aligning every step.

AccessForge can calculate straight stairs, build switchback stairs with landings, add guardrails, create elevated catwalks and place simple supports. Reopen generated assemblies later, change dimensions or rail settings, then regenerate safely.

Features:
• Automatic step/rise calculation
• Straight & switchback stairs
• Editable landings
• Catwalk/platform builder
• Left/right guardrails
• Optional support posts
• Read-only Preview
• Edit Existing & Regenerate
• Native Studio Undo/Redo
• No HTTP, telemetry or external services

Built for factories, warehouses, industrial maps, docks, utility areas and sci-fi facilities.

## Other Fields

Keywords: industrial stairs, switchback staircase, catwalk, landing, guardrail, factory, warehouse, maintenance access, utility facility, steelwork, editable stairs.

Privacy: AccessForge makes no HTTP requests and collects no data. Settings live as non-executable metadata in the user's place. No external service, login or runtime dependency.

Limitations: visual game geometry only; not certified engineering. Straight stairs, two-flight switchbacks and level straight catwalks. Maximum 1,000 parts/256 steps; original markers and metadata required for regeneration. No terrain fitting, automatic welds or collision checking. See LIMITATIONS.md.
