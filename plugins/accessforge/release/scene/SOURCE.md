The genuine ROOT utility/server facility supplies its shell, terminal furniture and server racks. `Setup.luau` adapts its output for offline product media: open cutaway, neutral steel/concrete colors, reduced decorative lighting, removed narrative signage/figures, and added maintenance platforms/columns/conduits. AccessForge itself generates the featured stairs, switchback and supported catwalk. No remote mesh, texture, audio or restricted asset is required.

The source and license belong only to the media build, not the commercial plugin. The saved demo contains geometry, simple local GUI signage and transparent AccessForge metadata, with no executable scripts.

## Rebuild

Build `build.project.json` using Rojo, install the separate AccessForge QA runner, and open the resulting place in Studio edit mode. Its media-only attribute triggers Setup once. After the success log, strip the ServerStorage build modules and ReplicatedStorage/HackerTycoon, then save as `AccessForge-Media.rbxl`. Keep the MIT notice beside all redistributed derivatives. Remove the QA runner from local Plugins afterwards.

Each scene stores `CameraCFrame`, `CameraFocus` and `FeaturedAssembly`. They are reproducible capture starting points, not product features. The commercial upload is exclusively `../../dist/AccessForge-v1.0.0.rbxm`.
