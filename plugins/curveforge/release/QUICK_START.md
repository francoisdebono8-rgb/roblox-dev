# CurveForge in one minute

1. Open CurveForge from Studio's Plugins toolbar.
2. Choose **New Path**, or select 2-8 BaseParts and **Use selected points**. Review/reorder the numbered list, then confirm its order.
3. Move the control points using Studio's Move tool.
4. Choose **Cable** and its thickness/style, or **Repeat**, select a source Part/Model and click **Source**. Set spacing or count.
5. Inspect **Preview**, then **Build**. One Studio Undo reverses the build.
6. Later select the generated parent Model, choose **Edit Selected CurveForge Model**, adjust the points/settings, then **Preview > Regenerate**.

Keep original controls and repeat source. To hide New Path markers from the game, set their Transparency to 1 in Studio; don't delete them while you still need regeneration.
