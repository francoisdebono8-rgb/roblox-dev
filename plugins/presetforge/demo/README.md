# PresetForge Creator Store demo

Open `PresetForge-Demo.rbxl` in Studio with PresetForge 2.0 installed. The place uses only Roblox primitives and contains no third-party assets or executable scripts.

## Screenshot 1: Choose exact fields

1. Select `Workspace/PresetForge-Demo/01_ChooseExactFields/SourceFixture/PF_Source_AccentLight`.
2. Open PresetForge and click **Save Recipe**.
3. Check `Brightness`, `Color`, and `Range`; enable **Attributes** and leave other fields unchecked.
4. Frame `01_ChooseExactFields` in the viewport.

## Screenshot 2: Filter + Preview

1. Choose the Project recipe **Teal Accent Lights**.
2. Select `Workspace/PresetForge-Demo/02_FilterPreview/PreviewTargets`.
3. Choose **Descendants** with class `PointLight`, name `Accent`, and tag `PF_DemoAccent`.
4. Click **Preview** and leave the detailed affected/matching rows visible.

## Screenshot 3: Apply safely

1. Reopen the place if screenshot 2 changed anything.
2. Choose the Project recipe **Safe Display Parts**.
3. Select `Workspace/PresetForge-Demo/03_ApplySafely/ApplyTargets`.
4. Choose **Descendants** with class `Part`, name `Display_`, and tag `PF_DemoDisplay`.
5. Click **Preview**, then **Apply**, then **Select affected**. Keep the success message and selected objects visible.

Before capture, hide account controls and unrelated plugins. Use a 16:9 crop containing the viewport, Explorer selection, and PresetForge widget only.
